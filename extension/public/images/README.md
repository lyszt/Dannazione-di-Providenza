# Extension Icons

Place your extension icons here:

- `icon-16.png` - 16x16px
- `icon-48.png` - 48x48px
- `icon-128.png` - 128x128px
- `icon.png` - Default icon

## Icon Requirements

### Firefox
- Format: PNG
- Sizes: 16x16, 48x48, 128x128
- Transparent background recommended
- Should represent the "Dannazione di Providenza" brand

## Suggested Design

- Use the purple/blue gradient theme (#667eea to #764ba2)
- Simple, recognizable symbol
- Works well at small sizes
- High contrast for visibility

## Tools

- [Figma](https://figma.com) - Vector design
- [GIMP](https://gimp.org) - Raster editing
- [Inkscape](https://inkscape.org) - Vector editing
- [RealFaviconGenerator](https://realfavicongenerator.net) - Icon generation
